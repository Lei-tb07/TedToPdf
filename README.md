# TedToPdf
快速生成双语文稿，英语学习者的福音
✨ 一款免费开源的 Chrome 浏览器扩展，一键导出 TED 官网双语演讲稿为 PDF 文件

## 📖 项目介绍
想用 TED 演讲稿练习英语，手动复制、排版演讲稿非常麻烦，网上同类导出插件大多需要付费。
所以自己开发了这个浏览器扩展，**完全免费、开源、无广告**，分享给同样想用 TED 学英语的小伙伴。

✅ 核心功能
- 读取 TED 官网演讲文稿（Transcript）
- 支持双语对照导出 PDF
- 页面悬浮快捷按钮，一键唤起功能面板
- 纯前端本地处理，**不上传你的任何数据**，隐私安全
- 适配 Manifest V3

⚠️ 限制说明
- 仅支持 TED 官网（ted.com）演讲页面
- 使用前需要手动打开网页上的 Transcript（文稿面板）
- 仅支持 Chromium 内核浏览器：Chrome、Edge、360浏览器等
- 不支持手机端

## 📥 安装教程（开发者模式加载）
1. 下载本仓库代码，解压到本地文件夹（路径不要带中文）
2. 浏览器地址栏打开：`chrome://extensions/`
3. 右上角打开【开发者模式】
4. 点击【加载已解压的扩展程序】，选中解压好的文件夹
5. 打开任意 TED 演讲页面，右下角会出现红色 PDF 悬浮球，代表加载成功

## 📝 使用步骤
1. 打开 TED 演讲页面，手动点开 Transcript，展开演讲稿
2. 点击页面右下角红色悬浮按钮，打开 TedToPDF 侧边面板
3. 选择你想要的语言版本（英文 / 双语）
4. 点击导出，直接在本地生成 PDF 文件
